## 개요

실시간 금융 데이터 서비스에서 WebSocket 연결 불안정 문제를 해결하기 위해 개발한 연결 관리 라이브러리입니다. WebSocket → SSE → 폴링 순으로 자동 fallback하며, 연결 복구 시 구독 상태를 자동으로 재동기화합니다.

## 주요 기능

- 지수 백오프(exponential backoff) 기반 자동 재연결
- WebSocket 실패 시 SSE, SSE 실패 시 폴링으로 순차 fallback
- 연결 복구 시 구독 상태 자동 재동기화
- React 훅 인터페이스 (`useRealtimeData`)

## 기술적 도전

### 구독 상태 재동기화

연결이 끊어진 동안 서버 상태가 변경될 수 있습니다. 재연결 시 클라이언트 상태와 서버 상태의 불일치를 해결하기 위해 snapshot 기반 diff 동기화를 구현했습니다.

```ts
class ConnectionManager {
  private strategy: 'websocket' | 'sse' | 'polling' = 'websocket';
  private subscriptions = new Map<string, Subscriber>();

  async connect() {
    for (const s of ['websocket', 'sse', 'polling'] as const) {
      try {
        await this.tryConnect(s);
        this.strategy = s;
        await this.resyncSubscriptions();
        return;
      } catch {
        continue;
      }
    }
  }
}
```

### React 훅 추상화

라이브러리 내부의 복잡한 연결 로직을 간단한 React 훅으로 추상화해 소비자 코드가 연결 전략을 몰라도 되도록 했습니다.
