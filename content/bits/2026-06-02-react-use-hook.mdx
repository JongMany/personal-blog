---
title: React의 use() 훅 동작 방식
date: 2026-06-02
tags: [React, hooks]
---

React 19에서 정식 도입된 `use()` 훅은 Promise나 Context를 읽는 데 사용된다.

```tsx
const data = use(fetchData());
const theme = use(ThemeContext);
```

기존 훅과 다르게 **조건문이나 반복문 안에서도 호출 가능**하다는 점이 특징이다.
Suspense와 함께 사용하면 비동기 데이터를 선언적으로 처리할 수 있다.
